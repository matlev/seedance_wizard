# Gate 0 G0.5 Stage 2 workload proposal

Status: versioned design proposed; owner review required; no media execution authorized

Authority: [G0.5 Stage 1 owner decisions](gate-0-g0.5-stage1-owner-decisions.md)

The machine-readable design is `eng/gate0/g0.5-stage2-workload-contract.json`. It closes the ambiguity between a layer count and an executable workload while keeping runtime-route, proof-adapter, and future product evidence separate.

## Workloads

| Workload | Exact shape | Purpose |
| --- | --- | --- |
| Baseline | 1 F1 identity-cycle layer and 1 F1 stereo sync track. | Route floor and long-form source. |
| Typical | F1 base plus retained 50%-alpha magenta picture-in-picture; four delayed, gained, panned 440/660/880/1000 Hz sources. | Real 2V4A composition with scale/crop/position/source alpha and distinguishable audio onsets. |
| Stress | F1 base, F2 landscape, cropped F2 portrait, and retained alpha overlay; eight delayed/gained/panned track instances. | Bounded 4V8A transform/mix pressure without adding a component or fixture family. |
| Long form | 60-minute F1 identity/audio cycle at 1080p25 with a unique 17-bit frame-index marker generated from a hash-pinned PPM atlas. | Continuous source-position identity, timestamp, audio, resource, cancellation, and disk integrity. |

All ordinary sources are current retained F1/F2/F3/F4/F8 bytes with exact sizes and SHA-256 in the contract. The proposed long-form marker atlas is generated by `eng/gate0/Generate-G05Stage2MarkerAtlas.ps1`; its 4,590,016-byte output and SHA-256 are locked in the contract, but owner approval and durable retention are required before execution. It uses only the already approved PPM decode, crop, nearest-neighbor scale, and overlay path. The contract supplies exact input tokens, stream maps, encoders, options, muxers, filter graphs, and 720p/1080p substitutions; a runner may not use auto-selection. Typical and stress mix only 48 kHz primitives, so the independent authored audio oracle does not depend on FFmpeg resampling behavior. Delayed onsets have typed 250 ms windows with the new and active tracks, expected channel frequencies, and required per-window metrics.

The direct 2A rows are `runtime-route` evidence. They do not exercise the current product builder or cache. The 2B rows are `p2-windows-wpf-measurement-adapter` evidence. No row is current product-composition evidence.

## Thread-policy scope

`one` resolves to one and `half-logical` resolves to eight on the 16-logical-processor reference machine. Each policy explicitly requests the value for every input video/audio decoder, ordinary filter pipeline, complex filter graph, selected output video encoder, and selected output audio encoder. The exact token placement is part of the contract.

These are requests to the named FFmpeg components, not a process-wide CPU cap and not proof that each component uses the requested workers. Actual process and UI behavior remains measured evidence.

## Matrix and fail-fast sequence

1. Complete and approve the audio oracle, workload contract, P2/WPF boundary, second private artifact copy, and smoke resource/free-space preflight.
2. Run one retained 1080p typical smoke for each admitted route/thread candidate—at most MP4 `one`, WebM `one`, and WebM `half-logical`.
3. Stop a route on deterministic integrity failure.
4. If every candidate passes, execute 72 WebM 2A attempts plus 36 conditional MP4 attempts under the 0.75 GiB retained-group ceiling.
5. Keep 2B concurrency at one and two only. For each route, deterministically select one post-2A thread policy by median wall time with the lower thread count winning a 1% tie. Each route/concurrency cell has six scenarios: cold warm-up, cold complete measurement, three warm complete measurements, and one warm cancellation measurement. This preserves the 24-scenario maximum for two routes while covering exact cold and warm semantics.
6. Run one 60-minute output per admitted route only after the sizing approval; 120 minutes remains deferred.

## Oracles

- Every 30-second output has 750 frames, ticks 0 through 29,960 at 40-tick cadence, and presentation end 30,000 in the 1/1000 comparison time base.
- Expected pixels are calculated independently from raw sources and declared scale/crop/source-alpha/z-order composition. Every decoded frame is checked using a one-frame buffer; full 30-second raw decodes are never retained.
- Expected mixed PCM is authored directly from the machine-readable workload track recipe, not from a second hand-copied recipe. Each typed onset window and the full mix are checked through the approved lossy-audio oracle.
- The long output has 90,000 frames, final frame tick 3,599,960, presentation end 3,600,000, and 172,800,000 audio samples per channel. Verification sequentially binds every frame index to `PTS = index * 40`, F1 identity `index mod 3`, and its unique 17-bit atlas marker using bounded memory; exact terminal EOF proves that no interval was skipped.
- Integrity permits zero unexpected frame, timestamp, stream, marker, orphan, partial-output, path, or cache-state deviations.

## Remaining approvals and external prerequisite

Owner approval is required for this exact contract, including the proposed marker-atlas fixture, before any smoke. The marker bytes must then be generated, hash-verified, and added to retained source closure. Separately, the current Gate 0 corpus needs a verified private second copy. The disconnected OneDrive directory is one local copy and does not satisfy that requirement; a genuinely separate private location or backend must be selected before execution.
